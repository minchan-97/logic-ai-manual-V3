# 교사 업무 매뉴얼 Q&A (Logic AI Manual)

나이스·K-에듀파인·회계·시도교육청 매뉴얼 PDF를 올리고 한국어로 질문하면,
관련 자료를 검색해 두 관점(절차 / 주의사항)으로 답하는 RAG 도구.

## ⚠️ 이 도구가 무엇이고 무엇이 아닌가

**무엇인가**
- 업로드된 PDF 안에서만 답을 찾는 RAG (Retrieval-Augmented Generation)
- 모든 답변에 출처 (파일명, 페이지) 강제 인용
- 두 관점(절차 안내 / 주의사항)으로 답이 갈리면 "직접 확인" 신호

**무엇이 아닌가**
- 법적·행정적 자문 아님
- 매뉴얼 외 내용(LLM 자체 지식) 사용 안 함 (system prompt에 강제)
- 실시간 시스템 화면이 아님 (매뉴얼은 최신이 아닐 수 있음)
- 최종 절차는 **반드시 행정실·교무부·해당 부서 확인 필요**

## 동작

1. 사용자가 매뉴얼 PDF 1~5개 업로드
2. PDF 파싱 (페이지별) → 청킹 (기본 800자, 100자 겹침) → OpenAI 임베딩
3. 사용자 질문 입력
4. 코사인 유사도로 top-k(기본 5) 청크 검색
5. 두 system prompt로 LLM 호출:
   - **절차 안내**: 단계 순서로 정리
   - **주의사항**: 빠뜨리기 쉬운 점, 흔한 실수
6. 두 응답의 임베딩 mismatch가 크면 "매뉴얼 모호함" 경고
7. 답변에 [출처: 파일명 p.N] 형식 인용 강제

## 설치 / 실행

```bash
pip install -r requirements.txt
streamlit run manual_app.py
```

`.streamlit/secrets.toml` 또는 환경변수:

```toml
OPENAI_API_KEY = "sk-..."
OPENAI_MODEL = "gpt-4o-mini"
OPENAI_EMBEDDING_MODEL = "text-embedding-3-small"
```

## 비용 (대략)

- **임베딩** (1회, 인덱스 빌드 시):
  - 100쪽 PDF 1개 ≈ 약 5~10원
  - 500쪽 매뉴얼 1개 ≈ 약 25~50원
- **질의** (질문마다):
  - 검색 임베딩 + 두 응답 chat + 두 응답 임베딩 ≈ 약 1~3원

## 개인정보

- PDF 본문은 OpenAI API로 전송됩니다.
- **학생 개인정보(이름, 주민번호 등) 포함 자료는 업로드하지 마세요.**
- 로컬 DB에는 본문 저장 안 함 (질문, mismatch 값, 판정만 저장).
- 인덱스는 메모리 안에만 존재 (재시작 시 사라짐).

## 정직한 한계

- **표·그림·수식이 많은 PDF**는 텍스트 추출이 부정확함.
- **스캔 PDF**는 OCR 안 됨 (텍스트 레이어 있는 PDF만 가능).
- **매뉴얼이 최신이 아닐 수 있음**: 나이스/회계 매뉴얼은 매년 개정. 답변 신뢰 전 출처 페이지를 직접 열어보세요.
- **청킹은 휴리스틱**: 의미 단위 보장 안 됨. 중요한 절차가 두 청크에 걸쳐 있으면 답변이 불완전할 수 있음.
- **두 관점 mismatch**는 매뉴얼 모호도의 신호일 뿐, 답변 정확성 보장 아님.
- **공통 환각 위험**: 두 관점이 비슷해도 둘 다 자료를 잘못 해석할 수 있음.

## 추천 사용 방식

1. 큰 매뉴얼(예: 나이스 사용자 설명서 500쪽)은 **본인 관심 부분만 잘라서** 업로드 (예: 학적관리 챕터만 50쪽).
2. 자주 묻는 업무별로 별도 인덱스를 운영 (학적용 / 회계용 / 복무용 등).
3. 답변을 받으면 **반드시 출처 페이지를 직접 열어** 확인.
4. 두 관점이 갈리는 답변은 보너스 검증 — 행정실에 가져가 물어보기.

## 파일 구조

```
manual_app.py   — Streamlit 메인 진입점 (매뉴얼 Q&A)
rag.py          — PDF 파싱·청킹·임베딩 인덱스·검색 (모델 의존부 격리)
safety.py       — v4 공유. 누적 차단 (선택)
cloud_features.py — v4 공유 (본 앱에서 미사용)
app.py          — v4 일반용 (Q&A, 본 앱과 독립 진입점)
```

## 다른 진입점

- `streamlit run app.py` — 일반 Q&A (v4 본체)
- `streamlit run manual_app.py` — 매뉴얼 PDF Q&A (이 도구)
